# [DIET COMPOSER APP](https://adrode.github.io/diet-composer-vanillaJS/)

## Basic version of the diet composer.
### Data for BMR is entered rigidly.

You select the number of products from which you want to make a meal. After the productPickers forms appear, you select a given product and set the weight of this product. The application summarizes kcal, macronutrients and price of selected products, so you can easily compare the values ​​of the meal you created to the planned values ​​for a given dish.
