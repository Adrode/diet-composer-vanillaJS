# [DIET COMPOSER APP](https://adrode.github.io/diet-composer-vanillaJS/)

## Basic version of the diet composer.
### You can find the extended version in my GitHub repositories or at the link [...]

Data for BMR is entered rigidly. You select the number of products from which you want to make a meal. After the productPickers forms appear, you select a given product and set the weight of this product. The application summarizes kcal, macronutrients and price of selected products, so you can easily compare the values ​​of the meal you created to the planned values ​​for a given dish.

The styling of the page is intentionally poor and unresponsive. The main task of the application is the working JS code. The extended version of the application is being built in React, where I am creating the final, extended and ready-to-use product for other users.
